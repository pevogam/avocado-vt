============================
Avocado-VT multi-VM examples
============================

This directory is the sample suite for Avocado-VT's multi-VM, stateful, and
graph-based testing features. It contains reference Cartesian configuration,
tests, controls, tools, utilities, and test data.

The canonical user documentation is
`Multi-VM, Stateful, and Graph-Based Testing
<../docs/source/MultiVMTesting.rst>`_. It explains how to select the suite,
choose between normal and graph-traversed execution, manage states with
``avocado env``, and use these files as a starting point for another suite.
